# Reporting a security issue

Use [GitHub's private vulnerability reporting](https://github.com/martin2844/slab-agents/security/advisories/new) for suspected vulnerabilities in Slab Agents. Do not open a public issue with exploit details or credentials.

Include the affected version or commit, installation method, expected security boundary, reproduction steps, and potential impact. Use a local test workspace and redact any real credentials or customer information.

For ordinary bugs and setup problems, use [Issues](https://github.com/martin2844/slab-agents/issues).

## Scope

This repository handles the web workspace, authentication, orchestration, integration access, and approval policies. Identify the affected component when the issue involves another Slab service so the report can be investigated in the right place.

Slab is under active development. Include the exact installed stack release or commit in your report; do not assume an older release or a development checkout has the same security behavior as the latest release.
